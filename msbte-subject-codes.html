Frequently asked questions

What is an MSBTE subject code?

Every MSBTE course has a unique code printed on its question paper and curriculum. You can use this paper code to download the previous year question papers of that subject.

How do I find my subject's code?

Search your subject in the table on this page, or look it up on the official MSBTE curriculum search. The code is also printed at the top of your question paper.

What does the code tell me about the semester?

In the K Scheme codes listed on this page, the third digit matches the semester. For example, a code starting with 315 belongs to Semester 5.

Is this the complete MSBTE subject code list?

No. This list covers popular K Scheme subjects for Civil, Mechanical, Computer/IT and Electrical branches, plus common subjects. More branches and subjects will be added. Always confirm a code on the official MSBTE curriculum.

Do different branches share the same code?

Yes, some common subjects, such as Strength of Materials (313308), are shared by more than one branch and appear under each of them.

How do I download papers using a code?

Press Download papers next to any subject, or enter the code on the download page, choose sessions and press Find Papers. It is free and needs no login.
